# 路由与页面设计

## 1. 设计原则

路由与页面设计遵循以下原则：

1. **`/dashboard` 是用户侧 AI 学习主入口**，承载普通学习对话、课程资料问答、资源生成、任务卡片和资源画布。
2. **课程选择不是强制前提**。用户可以选择课程进入课程学习场景，也可以不选择课程直接进入通用学习场景。
3. **课程内页面与通用能力解耦**。学习路径、课程资源、课程资料问答依赖课程上下文；普通 Chat、通用规划、画像分析和资源生成可以在无课程状态下运行。
4. **AI Room 是能力区域，不是必须独立为主入口**。`/dashboard` 内部的 AI 对话舱是主要使用形态，`/ai-room` 可作为独立深链或兼容入口。
5. **资源工坊由 ArtifactCanvas 承载**。`/resource-workshop` 只负责深链解析和任务恢复，不独立承担主要页面。
6. **管理端只做支撑与治理**，包括课程结构、知识库、模型网关、资源审核和运行监控。
7. **页面实现遵循 shadcn + 21st.dev 组件基准**。基础交互控件优先沿用 [shadcn/ui](https://ui.shadcn.com/)；用户侧 AI 对话、资源生成、资源大厅、学习工作台和展示型区块可参考 [21st.dev Community Components](https://21st.dev/community/components) 的组件化、预览优先和现代 SaaS / AI 产品审美。具体视觉与组件选型见 `docs/01-product-overview.md` 的“21st.dev / shadcn 组件设计基准”。

## 3. `/dashboard` — AI 学习工作台

### 3.1 页面定位

`/dashboard` 是用户侧最核心的 AI 学习工作台。它既能服务“已选课程”的课程学习，也能服务“未选课程”的通用学习。

页面包含：

* 顶部课程 / 模式状态区；
* AI 对话舱；
* 底部学习输入框；
* 快捷能力菜单；
* 课程资料问答显式模式；
* AI 方 ResourceTaskCard；
* 会话历史抽屉；
* split 模式下的 ArtifactCanvas。

### 3.2 顶部课程与模式状态区

顶部状态需要支持三种状态。

#### 状态一：已选择课程

```text
当前课程：深度学习
知识库已就绪
画像范围：全局画像 + 当前课程画像 + 当前会话
```

此时可用能力：

* 普通学习对话；
* 课程资料问答；
* 基于课程资料的资源生成；
* 课程学习路径；
* 课程资源推荐；
* 课程画像更新。

#### 状态二：未选择课程

```text
当前课程：未指定
通用学习模式
画像范围：全局画像 + 当前会话画像
```

此时可用能力：

* 普通学习对话；
* 通用学习规划；
* 通用资源生成；
* 通用画像更新；
* 主题型会话记录。

不可用或需要提示的能力：

* 课程资料问答；
* 课程学习路径节点；
* 课程资料引用；
* 课程掌握度更新。

#### 状态三：临时资料 / 临时任务

```text
当前课程：未指定
临时资料学习
画像范围：全局画像 + 当前文档会话
```

此时系统可以围绕临时上传资料或临时主题进行问答和资源生成，但不直接写入某门课程画像，除非用户主动选择“归档到课程”。

### 3.3 AI 对话舱

AI 对话舱支持：

* 普通学习对话；
* 知识点解释；
* 学习规划；
* 智能辅导；
* 课程资料问答；
* 基于课程资料引用的回答；
* 讲义生成；
* 代码实验生成；
* 阶段测评题生成；
* 错题补救卡生成；
* 拓展阅读包生成；
* 对已有资源继续追问；
* 查看引用与生成过程；
* 触发 Agent 工作流。

默认提示文案应根据是否选择课程变化。

已选择课程：

```text
我会结合当前课程、学习路径和你的画像进行学习辅导。普通问题默认走 Chat；需要基于课件回答时，请选择“课程资料问答”。
```

未选择课程：

```text
你当前处于通用学习模式。可以直接提问、规划学习或生成资料；选择课程后，我会进一步结合课程资料和学习路径。
```

### 3.4 默认输入框行为

默认输入框不走文档问答 API。

默认调用链路：

```text
用户输入普通学习问题
  ↓
POST /api/v1/ai/messages
  ↓
mode = default_chat
  ↓
AiOrchestrator
  ↓
ChatProvider
```

在未选择课程时，请求中的 `courseId` 可以为空。

```ts
{
  courseId: null,
  message: userInput,
  mode: 'default_chat',
  scope: 'general'
}
```

### 3.5 快捷能力菜单

推荐菜单结构：

```text
课程资料问答
高白话讲义
PyTorch 实操案例
阶段测评题
错题补救卡
拓展阅读包
```

其中：

* “课程资料问答”只在已选择课程且课程资料可用时启用；
* 其他资源生成入口可以在有课程和无课程状态下运行；
* 无课程状态下生成的资源默认是通用资源，可以后续归档到课程；
* 已选择课程时生成的资源默认带课程上下文。

### 3.6 课程资料问答模式

课程资料问答用于基于当前课程已经上传并完成云端向量化的资料回答问题。它不属于资源生成任务，不创建 ResourceTaskCard，不打开 ArtifactCanvas。

调用链路：

```text
用户点击“课程资料问答”
  ↓
输入课程资料问题
  ↓
POST /api/v1/ai/messages
  ↓
mode = course_rag_qa
  ↓
AiOrchestrator
  ↓
CourseRagQaService
  ↓
CloudRagProvider
```

可用条件：

* 当前已选择课程；
* 当前课程已绑定 CloudRagProvider；
* 当前课程存在远端知识库 ID；
* 当前课程至少有一个文档处于可问答状态；
* 云端 RAG 服务健康；
* 文档已完成解析、切分和向量化。

无课程状态下点击“课程资料问答”应提示：

```text
课程资料问答需要先选择课程。你也可以继续使用普通 AI 问答，我会基于通用知识进行解释。
```

### 3.7 资源生成入口

资源生成入口包括高白话讲义、PyTorch 实操案例、阶段测评题、错题补救卡、拓展阅读包等。

从学习路径节点进入资源生成时，URL 只携带 `type`、`concept`、`path_node` 和资料范围等结构化上下文，不把完整提示词暴露在地址栏。`/dashboard` 对话舱读取节点上下文后在本地组装可编辑草稿，并选中对应资源类型；用户确认或补充后再创建资源任务，避免直接生成泛化资源。

调用链路：

```text
用户点击资源生成入口
  ↓
POST /api/v1/resource-tasks
  ↓
actionType = resource_generation
  ↓
ResourceAgent
  ↓
ChatProvider
  ↓
ResourceTaskCard + ArtifactCanvas
```

已选择课程时，任务携带：

```ts
{
  scope: 'course',
  courseId,
  pathNodeId,
  conceptId,
  resourceType,
  prompt,
  needCourseEvidence
}
```

未选择课程时，任务携带：

```ts
{
  scope: 'general',
  courseId: null,
  topic,
  resourceType,
  prompt
}
```

### 3.8 ResourceTaskCard

ResourceTaskCard 出现在 AI 方消息中，用于承载资源生成任务。卡片包含：

* 资源类型；
* 任务状态；
* 生成进度；
* 是否绑定课程；
* 是否基于课程资料；
* 引用覆盖状态；
* 打开预览；
* 查看生成过程；
* 失败提示与重试。

设计原则：

* 用户消息只展示用户自然语言；
* 资源入口和生成状态只出现在 AI 方消息；
* 课程资料问答不使用 ResourceTaskCard；
* ResourceTaskCard 与右侧 ArtifactCanvas 联动。

### 3.9 ArtifactCanvas

当用户点击资源任务卡片的“打开预览”，或触发资源生成时，`/dashboard` 可以进入 split 模式。

```text
左侧：AI 对话舱
右侧：ArtifactCanvas 资源画布
```

ArtifactCanvas 承载：

* 资源生成进度；
* 生成草稿；
* 最终正文；
* 引用来源；
* outline；
* 版本；
* 编辑；
* 保存；
* Markdown / DOCX / PPTX 导出；
* 浏览器打印 / 另存 PDF；
* 思维导图 SVG / PNG 导出；
* 多智能体工作流概览和 Trace 时间线；
* 提交资源大厅或审核；
* 版本恢复；
* 归档到课程。

其中 `resourceType = quiz` 的阶段测评题不应继续按纸质 Markdown 文档展示。画布需要切换为在线测评工作台：

* 左侧为题号导航、完成进度、用时和暂存状态；
* 中间为真实作答控件，包括单选、多选、填空和简答输入；
* 右侧为提交状态、评分结果、逐题反馈和画像更新提示；
* 答题中不开放“问 AI”，只允许填写、暂存、清空和提交；
* 提交评分完成后才开放“问 AI 解析错题”，并携带题目、学生答案、参考答案、评分反馈和薄弱点进入 AI 学习室；
* 若资源缺少标准答案或评分要点，应允许查看和填写题目，但不得伪造可靠自动评分，需提示重新生成或补全评分依据；
* 若资源未绑定课程知识点，应提示无法写入课程画像，避免把无上下文测评误写入画像。

无课程场景生成的资源，需要提供“关联课程 / 归档到课程”入口。

### 3.10 会话历史抽屉

会话历史需要区分：

* 普通 Chat 历史；
* 课程资料问答历史；
* 资源生成任务历史；
* 按课程隔离的课程会话；
* 未指定课程的通用会话；
* 临时资料会话。

用途：

* 保留学习连续性；
* 支持用户回到历史问答；
* 为画像更新提供证据；
* 区分普通回答和基于资料回答的来源。

## 4. `/learning-path` — 学习路径

### 4.1 页面定位

学习路径是课程内页面。它回答的是：

> 用户在某门课程中当前学到哪里，下一步应该学什么，哪些节点需要补救，哪些资源可以辅助当前节点学习。

因此，该页面必须有明确课程上下文。

### 4.2 无课程状态

用户未选择课程时访问 `/learning-path`，页面不应随便展示某门默认课程，而应显示课程选择引导：

```text
学习路径需要先选择一门课程。请选择课程后查看章节路径、掌握度和下一步学习建议。
```

可提供：

* 课程选择器；
* 最近学习课程；
* 推荐课程；
* 返回通用学习模式。

### 4.3 页面内容

已选择课程时，页面包含：

* 紧凑总览栏：当前节点、今日建议、完成进度，以及以图标文字呈现的总掌握度、待学习节点、资料来源和学习单元；
* 课程资料范围：可在全部课程资料和单份教材之间切换；选择单份教材时，可在当前页打开原始教材预览，便于对照原文学习；
* 原始教材预览：PDF 弹窗内提供学习导航侧栏，支持章节目录跳转、全文搜索命中定位、搜索历史、最近阅读页恢复、当前页书签和页面笔记；页面笔记支持删除当前页和导出 Markdown；目录优先基于 PDF 文本索引和本地切片标题自动生成，无切片数据时也可使用页面分组兜底；搜索同时覆盖 PDF 文本索引和本地切片，扫描型 PDF 或文本层不可用时仍可通过切片命中跳页；
* 概念掌握度热力流：章节仍可折叠，节点只展示序号、知识点名称、掌握度和状态；已掌握节点使用勾选、绿色轨道和置灰文字，当前焦点节点高亮，前置依赖已满足但尚未开始的节点显示“待学习”并使用蓝色可学轨道，首个待学习节点以轻微呼吸光提示进度断点，仅前置依赖未满足的节点显示“未解锁”并低显色；
* AI 动态补救节点：当节点为补救状态时，以黄色 AI 插入卡展示薄弱点和补救原因，点击后聚焦补救任务；
* 当前学习闭环：展示当前节点、掌握度、推荐学习步骤、前置依赖、后续路径和掌握证据；节点学习进度只统计核心学习闭环，不把所有可生成资源强制纳入进度；当讲义、导图或题包已经生成时，学习步骤直接提供“查看已生成资源”入口，不重复触发生成；
* 当前节点资源包：在辅助栏展示讲义、思维导图、阶段测评题、错题补救卡、代码实操、教学图解包、拓展阅读包和课程资料问答等资源类型；资源包完整度独立统计，用于体现多智能体生成成果，不替代掌握度或学习进度；完整度只统计可生成资源，课程资料问答作为功能入口单独展示；
* 资源遮罩预览：用户点击已生成资源时，在学习路径页内打开全页遮罩预览，并复用资源生成时的原视觉画布；讲义使用文档预览画布，思维导图使用导图画布，阶段测评题使用可作答测评面板，而不是降级为只读 Markdown。遮罩右侧保留资源信息和引用依据，关闭后回到原节点工作台，不离开学习路径。预览提供进入资源中心完整详情的次级入口；
* 多智能体分工提示：资源包内按讲解 Agent、结构 Agent、练习 Agent、诊断 Agent、实操 Agent、图解 Agent、拓展 Agent、检索 Agent 等角色展示生成职责；未生成资源提供深链入口，进入 `/dashboard` 后由对话舱生成可编辑草稿并创建 ResourceTaskCard。

### 4.4 与 `/dashboard` 联动

```text
用户在 /learning-path 选择节点
  ↓
点击课程资料问答 / 生成讲义 / 生成代码实验 / 生成自测题
  ↓
系统携带 courseId、pathNodeId、conceptId、resourceType 和资料范围进入 /dashboard
  ↓
课程资料问答进入 course_rag_qa 模式
  ↓
资源生成入口由对话舱根据节点上下文生成可编辑草稿，用户确认后创建 ResourceTaskCard
  ↓
ArtifactCanvas 展示生成过程和正文
```

```text
用户在 /learning-path 点击已生成资源
  ↓
学习路径页内打开资源遮罩预览
  ↓
用户阅读正文、查看引用依据，或进入资源中心完整详情
  ↓
关闭遮罩后回到当前节点工作台
```

## 5. `/calendar` — 学习日历

### 5.1 页面定位

学习日历是学习路径的时间视图，用于回答：

> 用户今天、本周和本月应该什么时候学习、复盘、测评或查看资源。

当前实现同时包含真实可保存日程与系统建议事项。页面会读取后端 `learning_schedule_items` 中的已保存学习安排，也会读取课程路径、掌握度、课程资源和公告数据，把可执行学习事项投射到日期格中。用户可以把系统建议保存为日程，也可以把已保存事项标记完成或重新计划。

### 5.2 数据来源

课程模式下，学习日历聚合：

* `GET /api/v1/courses/{course_id}/path`：当前学习节点、待复盘节点、待开始节点和掌握度；
* `GET /api/v1/resources`：课程资源复习入口；
* `GET /api/v1/announcements`：公告和维护提醒；
* `GET /api/v1/courses/{course_id}/mastery`：课程总掌握度概览。
* `GET /api/v1/learning-schedules`：当前用户已保存的学习日程事项，支持课程、日期和状态筛选。
* `POST /api/v1/learning-schedules`：把系统建议或用户自定义事项保存为真实日程。
* `PATCH /api/v1/learning-schedules/{item_id}`：更新日程状态、日期、标题和元信息。

未选择课程时，页面展示通用学习周计划，引导用户通过 AI 学习室制定主题、生成讲义、复盘问题和更新全局画像。

### 5.3 页面内容

页面包含：

* 顶部月份切换和“今天”快捷回到当前日期；
* 统计卡片：本月安排、待关注、已掌握、选中日期安排数；
* 课程上下文条：当前课程、总掌握度、安排来源；
* 月份日历格：以圆点标记学习、复盘、资源、小测和公告；
* 右侧日期详情：展示选中日期的可执行事项，并链接到 AI 学习室、学习路径、资源大厅、练习评估或公告详情；
* 快捷操作：底部“问 AI 调整计划”和“进入测评”会把选中日期、课程和知识点上下文写入跳转参数，目标页面自动预填输入框，用户确认后手动发送或提交；
* 日程操作：系统建议可保存为日程；已保存日程可标记完成或重新计划；
* 近期安排列表：展示接下来 7 项事项，便于快速继续编排。

### 5.4 与其他页面联动

```text
用户从顶部日历按钮或左侧 Dock 进入 /calendar
  ↓
选择日期或查看近期安排
  ↓
学习事项跳转 /ai-room 或 /learning-path
  ↓
资源事项跳转 /resource-hall?preview={resource_id}
  ↓
小测事项跳转 /assessment，并预填测评输入框
  ↓
公告事项跳转 /announcements?active={announcement_id}
```

学习日历只负责组织和呈现“何时做什么”，不直接创建资源生成任务。保存和完成日程会写入学习事件，作为画像、学习进度自然语言报告和后续路径调整的证据来源之一；掌握度更新仍由对话、测评、路径和资源使用事件完成。

## 6. `/announcements` — 公告中心

### 6.1 页面定位

公告中心用于集中展示系统通知、维护公告、规则变更、课程通知和功能更新。顶部导航应显示未读数量，重要公告可通过顶部条、弹窗、Toast 或页面卡片主动提醒用户。

### 6.2 数据来源

公告中心读取：

* `GET /api/v1/announcements/summary`：顶部未读数和主动展示公告；
* `GET /api/v1/announcements`：公告列表，支持分类、优先级、展示类型和未读筛选；
* `GET /api/v1/announcements/{announcement_id}`：公告详情；
* `POST /api/v1/announcements/{announcement_id}/read`：标记单条公告已读；
* `POST /api/v1/announcements/{announcement_id}/dismiss`：关闭某种展示方式；
* `POST /api/v1/announcements/read-all`：全部标记已读。

### 6.3 页面内容

页面包含：

* 公告筛选：全部、未读、重要、维护、课程、系统等；
* 重点公告卡片：展示置顶或高优先级公告；
* 左侧公告列表：标题、摘要、优先级、展示类型、时间和未读状态；
* 右侧详情：Markdown 正文、行动按钮、发布时间、生效时间和过期时间；
* 全部已读入口。

公告必须按当前用户角色过滤，普通用户不能看到仅管理员可见的公告。用户关闭公告只影响自己的展示状态，不改变公告发布状态。

## 7. `/resource-hall` — 资源大厅

### 7.1 页面定位

资源大厅用于沉淀、筛选、复用和推荐学习资源。它通过 `GET /api/v1/resources/hall` 获取后端聚合结果，同时支持课程资源、通用资源、个人生成资源、社区审核通过资源、精选资源和推荐资源。

### 7.2 资源范围

资源大厅应支持范围切换：

```text
全部资源 ｜ 当前课程资源 ｜ 通用资源 ｜ 我的生成 ｜ 社区资源 ｜ 推荐资源
```

其中：

* 当前课程资源：绑定某门课程的资源；
* 通用资源：未绑定课程但可用于通用学习的资源；
* 我的生成：用户通过 AI 生成并保存的资源；
* 社区资源：经资源审核通过或标记精选后公开复用的资源；
* 推荐资源：根据全局画像、课程画像、课程上下文和资源偏好推荐的资源。

资源范围、类型、难度的筛选项和数量必须来自后端 `filters`，不能在前端用静态演示数据伪造。

### 7.3 页面内容

资源筛选区包含：

* 搜索框：支持标题、摘要、类型、推荐理由和结构化推荐证据检索；
* 类型筛选：全部、讲义、题库、代码实验、PPT 大纲、视频脚本、拓展阅读、错题补救卡、教学图解包等；
* 难度筛选：全部难度、初级、中级、进阶；
* 范围筛选：全部资源、当前课程资源、通用资源、我的生成、社区资源、推荐资源；
* 当前筛选摘要和清空筛选入口；
* 本页证据覆盖提示。

列表字段包含：

* 资源标题；
* 类型；
* 资源范围；
* 关联课程；
* 关联知识点；
* 更新时间；
* 是否基于课程资料；
* 引用覆盖率；
* 是否推荐；
* 是否精选；
* 推荐依据、生成依据和结构化推荐证据，包括画像匹配、薄弱点、掌握度短板、最近学习事件和引用质量；
* 预计学习时长；
* 本地学习状态：已收藏、待学习、已学完；
* 浏览数和复制数；
* 审核状态；
* 使用入口。

卡片数字、统计区、分页和详情弹层必须使用同一份后端资源数据：

* `stats` 展示总资源、课程资源、通用资源、个人资源、社区资源、推荐资源、精选资源、引用资源、平均质量、浏览数和复制数；
* `highlights` 展示精选、推荐和最近更新资源；
* `pagination` 控制真实分页，不得只在前端截取演示列表；
* 详情弹层通过 `GET /api/v1/resources/{resource_id}` 读取正文、引用、版本、互动计数和审核状态，卡片摘要与详情字段不得出现口径不一致。

资源操作包括：

* 在右侧“下一步行动”中继续待学资源、查看画像推荐或上传个人资源；
* 在学习清单中打开已收藏、待学习和已完成资源；
* 复制到个人资源；
* 编辑并创建新版本；
* 提交资源大厅审核；
* 归档到课程；
* 删除个人资源或批量删除个人资源；
* 查看版本记录、引用依据和学习状态。

## 9. `/assessment` — 练习评估

练习评估承接学习闭环中的独立答题、提交评分、评分后问 AI 和画像更新能力。

## 10. `/personal-settings` — 个人设置

个人设置用于管理：

* 账号资料；
* 课程分配；
* 学习偏好；
* 全局画像纠偏；
* 个人模型覆盖；
* 外观主题（背景与壁纸）；
* 隐私与数据管理。

当前页面至少应支持：

* 修改当前用户显示名称；
* 查看登录邮箱、账号 ID、权限角色和课程访问状态；
* 查看默认模型服务商、个人覆盖说明和隐私保留策略；
* 切换工作台与登录页的外观主题：选择预设壁纸/颜色、上传自定义图片、切换文字明暗模式、调整背景遮罩透明度；
* 导出设置摘要；
* 清理本地学习草稿、资源互动和临时 UI 状态；
* 安全退出登录，并撤销当前会话令牌。

个人模型覆盖只覆盖 ChatProvider，不覆盖管理端课程资料云端 RAG。课程资料问答必须依赖管理员配置的 CloudRagProvider 和课程绑定。

### 10.1 外观主题偏好

外观主题为用户级偏好，仅保存在当前浏览器 localStorage（键名 `zhike-appearance`），不落库、不跨设备同步。

* **作用范围**：登录后的工作台（`.ai-workspace-shell`）与登录页（`.auth-page`）。用户主题优先于管理员 `login_background` 配置；用户未启用自定义主题时，登录页回退到管理员配置。
* **背景来源**：默认外观（系统渐变）、预设壁纸（6 张，由文生图 API 生成）、预设颜色（8 个纯色/渐变）、自定义上传（PNG/JPEG/WebP，≤2MB，自动压缩到 1920px 宽）。
* **文字明暗**：用户手动切换亮色/深色文字。选择预设时自动套用推荐明暗模式，用户可随后手动覆盖。暗色文字模式下，顶栏、对话气泡、输入框、个人设置面板等关键元素切换为半透明深色玻璃质感。
* **背景遮罩**：0-100% 透明度滑块，用于在繁杂背景下提升前景文字可读性。
* **实现要点**：`frontend/src/config/appearance.ts` 提供 store（读写 localStorage + CustomEvent 广播），`frontend/src/config/appearance-presets.ts` 提供预设库，`frontend/src/hooks/useAppearance.ts` 提供 React 订阅 Hook。`WorkspaceLayout` 与 `AuthPage` 在根节点挂载 `data-theme`/`data-bg-mode` 属性与 `--workspace-*` CSS 变量，由 `styles/index.css` 引入的 `4-components/workspace-theme.css` 等覆盖层统一渲染。

## 12. 助教端页面（TA Portal）

### 12.1 页面定位

助教端面向教学助理，覆盖「班级 → 作业/测验 → 批改 → 诊断 → 预警 → 公告」的完整教学闭环；学生端新增我的班级、课程作业、随堂测验、消息通知四个页面，与助教操作实时联动：教师建班生成邀请码，学生凭码入班，形成「教师建班 → 学生入班 → 班内教学」的闭环。

### 12.2 布局规范

所有页面严格遵循 `docs/layout-spec.md`：顶级标题使用 Page Header（裸页头，无容器、无卡片、无边框），标题下方操作区使用 PageHeaderToolbar 变体 1（左对齐操作栏）或变体 2（左对齐 Tab 选项卡栏），标题与说明文案均为简体中文，全部元素默认左对齐。

### 12.3 页面清单

| 路由 | 页面 | 主要区块 |
|---|---|---|
| `/ta` | 助教工作台 | 统计卡、提交/预警趋势面积图、待办事项、风险预警列表。 |
| `/ta/class-management` | 班级管理 | 班级卡片列表、学生抽屉、班级与学生的增删改、邀请码展示/复制/重置、成绩 CSV 导出。 |
| `/ta/grading` | 批改中心 | 批改中心（内分「课后作业 / 批改记录」两个子区）与随堂测验两个 Tab；课后作业支持布置主观题/客观题并发布/关闭，批改记录支持提交详情、手动评分、AI 批改，随堂测验支持从题库选题布置、发布/关闭/删除与成绩统计。 |
| `/ta/lesson-prep` | 备课助手 | 教案生成表单、生成中的流式提示、教案编辑、发布。 |
| `/ta/diagnosis` | 学情诊断 | 班级对比、薄弱点、学生雷达图、趋势线图、教学建议。 |
| `/ta/continual` | 持续学习中心 | 遗忘风险预测列表、错误模式 TOP3、AI 反馈闭环统计与评分趋势、画像维度趋势图、进化日志时间线、「触发一轮进化」操作。 |
| `/ta/resource-review` | 资源审核 | 待审队列、通过/驳回动作与状态展示。 |
| `/ta/announcements` | 公告管理 | 公告列表、创建/编辑表单（含目标班级多选）、置顶与撤回。 |
| `/assignments` | 课程作业（学生） | 作业列表（多题作业显示题目数）、多题逐题作答（单选/多选/判断/填空/简答/代码）、客观题即时判分、单题文本提交。 |
| `/quizzes` | 随堂测验（学生） | 测验列表、在线作答、即时判分。 |
| `/notifications` | 消息通知（学生） | 通知收件箱、未读标记、一键已读。 |
| `/classes` | 我的班级（学生） | 邀请码入班、班卡信息、邀请码复制、退出班级。 |
