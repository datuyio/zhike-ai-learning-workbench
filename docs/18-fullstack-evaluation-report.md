### 1.6 发现并修复的真实缺陷 ⚠️

**问题**：本地 RAG 检索失效。根因是 `LOCAL_EMBEDDING_CACHE_DIR` 默认相对路径 `./storage/models`，当后端进程启动目录非 `backend/` 时解析到错误位置 → 找不到本地 Embedding 模型 → 回退 HuggingFace 联网（不可达）→ Embedding 加载失败 → 知识检索 0 命中。

**修复**：在根 `.env` 显式配置绝对路径：
```env
LOCAL_EMBEDDING_CACHE_DIR=D:/Develop/Challenge Cup/backend/storage/models
```
**验证**：重启后端后，首次检索 11.2s 加载模型、命中真实知识片段，embedding 输出 512 维正确。

## 四、技术架构与实现

```text
前端 React 18 + TS + Vite（WorkspaceLayout 三模式外壳）
   │  HTTP(262) / WebSocket(2, auth 帧鉴权)
后端 FastAPI + Python 3.12
   ├─ AI 编排层：AiOrchestratorService（统一调度）
   │    ├─ HybridIntentRouter（四层意图路由）
   │    ├─ AgentWorkflow（LangGraph 八节点状态机）
   │    └─ 资源生成流水线（取证→画像→生成→核验→安全→保存）
   ├─ 模型网关：15+ 供应商（云端 API + 本地 LoRA）
   ├─ 知识服务：双 RAG 后端（本地 pgvector ‖ 讯飞 ChatDoc）
   └─ 业务域：课程/画像/评估/资源/TA/公告/沙箱/运维
数据层 PostgreSQL 16 + pgvector 0.8.6（82 表） + Valkey（降级路径）
微服务 代码沙箱（Node+Pyodide WASM）· LoRA 推理服务（8002）
```

**关键技术**：LangGraph（多智能体编排）、semantic-router（语义路由）、QLoRA（模型微调）、pgvector + BM25（混合检索）、Pyodide + SharedArrayBuffer（沙箱中断）、Pydantic 结构化校验（防幻觉）。

## 五、优势特点逐一剖析

1. **本地微调大模型**：Qwen2.5-7B + QLoRA（7053 条教材 QA），回答风格转为「教材 QA 式」，可离线私有部署，数据不出校；
2. **本地混合 RAG 知识库**：pgvector 向量 + jieba BM25 加权融合（0.7/0.3），24170 切片引用可溯源；
3. **双 RAG 后端策略化**：本地 pgvector 与讯飞 ChatDoc 配置即切换，本地优先、云端可选；
4. **多智能体资源生成**：LangGraph 六节点流水线 + 双执行路径降级，支持 10 类资源，端到端实测完成；
5. **HybridIntentRouter 四层意图路由**：显式→规则→上下文→语义→LLM Judge→澄清，精准识别学习意图；
6. **四层动态学情画像**：全局/课程/会话/跨课程 + 证据链 + 置信度递增 + 用户纠偏；
7. **WASM 代码沙箱**：Pyodide worker 线程 + SharedArrayBuffer 中断，真正可打断死循环；
8. **TA function calling Agent**：11 工具，写操作需教师人工确认（模型提议、系统裁决、人工执行）；
9. **结构化输出纵深防御**：提示词→JSON mode→Pydantic 校验→修复重试→标准化降级，题单 100% 可评分；
10. **全链路可观测**：trace id 贯通、意图路由日志、RAG 日志、模型调用日志、运维大盘；
11. **前端工程化**：单一 Mock 开关 + 契约测试、路由驱动工作台三模式外壳、WS 三级降级；
12. **模型网关多供应商**：15+ 供应商、候选链降级、预算额度、健康冷却、热重载。

## 六、核心亮点提炼 —— 王牌亮点

### 6.1 杀手锏亮点：**「私有化 · 可进化 · 可信的 AI 学伴大脑」**

当前市面上的 AI 学习工具，绝大多数是「云端大模型 API 套壳」：问答靠 GPT/DeepSeek、知识库靠云端向量服务，一旦断网或涉及敏感数据（未成年人学情、版权教材、内部讲义）就无法使用。本项目用三项自研底座打破了这一格局，构成**别人难以同时复制的三角优势**：

### 6.2 三大差异化支柱

**支柱一 · 全栈私有化（数据主权）**
- 本地微调大模型（Qwen2.5-7B LoRA）+ 本地 Embedding（BGE-small-zh）+ 本地向量库（pgvector 24170 切片）+ 本地混合检索（BM25+向量）；
- **断网即可完整运行**核心 AI 能力（学科对话、课程资料问答、资源生成）；
- 数据不出校，满足教育数据安全合规（这是学校/政企采购的硬门槛）。

**支柱二 · 可持续进化（越用越懂学生）**
- 不是静态问答，而是「对话 → 测评 → 纠偏 → 画像 → 资源生成 → 再诊断」的闭环飞轮；
- 每个学习行为都沉淀为画像证据，反哺下一次辅导、路径规划和资源推荐；
- LoRA 架构支持用真实学生反馈**持续微调**，模型随使用越用越贴合教学场景。

**支柱三 · 可信零幻觉（教育刚需）**
- 检索低置信拒答（阈值 0.65）+ 引用核验 + 结构化输出五层校验 + 画像证据链；
- 教育场景对"编造知识点"零容忍，这套"检索前防幻觉、生成后验引用、结构化强校验"的三道闸门是本项目的可信底座。

### 6.3 对比赛评分的价值

- **创新价值（35%）**：私有化离线部署 + 本地微调模型 + 可进化闭环，是"从 0 到 1"的原创组合，非功能堆砌；
- **功能实现（45%）**：三端口 36 页面 + 262 端点 + 82 表 + 10 类资源生成 + 微调/RAG/沙箱全链路实测通过；
- **技术先进性**：LangGraph 多智能体、QLoRA、混合检索、WASM 沙箱、语义路由五件套均为业界主流前沿技术。
